# External Packages
External packages used for various ISSM configurations

Historically, we would host certain external packages at https://issm.ess.uci.edu/files/externalpackages to be downloaded, compiled, and used as part of the configuration for ISSM. We are moving away from this centralized paradigm as it is more vulnerable to network outages.

When setting up an external package installation script in the ISSM code repsository, please supply a URL for downloading the source code from the developer's repository. If this is not possible (e.g. you need to pin a specific release and the developer has stopped hosting it), feel free to commit the source to this repository,
